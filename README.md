# AI Agent Orchestrates Complex Tasks

This example demonstrates the core concept of an AI agent orchestrating multiple 'skills' (functions) to complete a complex, multi-step task. It simulates how an agent acts as a project manager, breaking down a high-level goal into sub-tasks and passing context (information) between these skills to achieve the final objective.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
